# PAUSA

PAUSA is a digital literacy platform designed to help older adults recognize and prevent online deception, including phishing, deepfakes and voice cloning.

**Built for Youth Hackathon 2026.**

> **Live Demo:** https://pausa-khaki.vercel.app/

## About

PAUSA provides a calm, accessible learning experience focused on digital safety, autonomy and confidence. The platform also connects family members and educators as a support network without compromising the learner's independence.

## Features

- **Guided digital literacy learning** focused on real-world online threats such as phishing, deepfakes, voice cloning and fraudulent messages.
- **Accessible learning path** designed for older adults, with clear navigation, readable interfaces and one primary action at a time.
- **Family connection system** that allows relatives to support the learner without interfering with their autonomy.
- **Positive progress tracking** focused on confidence and completed milestones rather than mistakes or failure metrics.
- **Educator dashboard** for guided classroom sessions and community workshops.
- **Theater Mode** for presenting lessons and simulations in group environments.
- **Aggregate reporting** for educators and institutions without exposing individual learner performance.

## User Profiles

PAUSA is designed around three complementary profiles:

1. **Older Adult:** the primary learner. Uses a simple, accessible interface to practice identifying digital threats in a safe environment.
2. **Family Member:** provides lightweight support through family connections, progress summaries and conversation prompts.
3. **Educator:** uses PAUSA to conduct digital literacy workshops, guide group activities and obtain aggregate learning metrics.

## Getting Started

Clone the repository:

```bash
git clone <repository-url>
cd pausa
```

Install dependencies:

```bash
npm install
```

Start the development environment:

```bash
npm run dev
```

## Design Principles

PAUSA follows a **dignity-first** approach to digital education. The interface avoids patronizing language, excessive gamification and punishment-based feedback. Instead, it prioritizes:

- Clear and accessible interactions
- High readability
- Low cognitive load
- Positive reinforcement
- Learner autonomy
- Privacy-conscious family support
- Simple tools for non-technical educators
